# mktbox

Free marketing tools at [mktbox.xyz](https://mktbox.xyz). Small tools that each do one job well. No account, no paywall, nothing to upgrade.

| Tool | Route | Status |
| --- | --- | --- |
| QR code generator | `/qr` | Live |
| Email signature generator | `/signature` | Live |
| Keyword ideas | `/keywords` | Live |
| Page speed audit | `/speed` | Live |
| UTM builder | `/utm` | Live |
| Link preview | `/preview` | Live |
| LinkedIn post formatter | `/linkedin` | Live |
| Image resizer | `/resize` | Live |
| Headline analyzer | `/headline` | Live |



## Run it locally

```bash
npm install
npm run dev
```

Built with Next.js. QR codes are drawn with [qr-code-styling](https://github.com/kozakdenys/qr-code-styling) and generated entirely in the browser.
